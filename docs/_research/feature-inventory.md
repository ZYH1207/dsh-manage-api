#### 12. 关键考古发现：白名单已开放，UI 仍宣称「未开放」

`lib/write-proxy.js:25-44` 的 18 条规则里，`:42` 有一条推进注释：

```js
// P3.2：比价页改价/忽略模型、决策页上下移、汇率刷新
```

也就是说，**改价、决策排序、汇率刷新、站点登录的写通道后来被补进了白名单**，但对应 UI 的禁用状态与 title 文案没跟上，仍在告诉用户"宿主没开放"。

| 白名单规则（已放行） | UI 现状（仍按未开放渲染） | 结论 |
|---|---|---|
| `PATCH /api/offers/:id` — `lib/write-proxy.js:43` | `50-pricing.js:99` `PRICING_READONLY_TITLE`：「宿主写通道未开放改价（PATCH /api/offers/:id 不在白名单）：这里只读，改价请到 daemon 网页版」 | **文案与代码直接矛盾**：规则存在 → 改价可接通，只是前端没接 |
| `PUT /api/decisions/[model]/order` — `lib/write-proxy.js:44` | `60-decision.js:7` `DECISION_ORDER_TITLE`：「…不在白名单…顺序仍按「有效成本 = 价格 ÷ 质量」自动计算」 | 手动排序可接通 |
| `POST /api/fx/refresh` — `lib/write-proxy.js:45` | `40-benchmark.js:206` title：「拉取汇率要 POST /api/fx/refresh」（暗示不可行） | 刷新汇率可接通 |
| `POST /api/providers/:id/login` — `lib/write-proxy.js:33` | `10-monitor.js:1023` title：「需要站点后台账号密码；插件侧还没移植登录表单」 | 通道在，**只缺表单** |
| `POST /api/providers/:id/detect-kind` — `lib/write-proxy.js:30` | **无任何 UI 入口**：系别只在新增表单里手选（`10-monitor.js:850-859`） | **规则空转**（死规则） |

**反例（禁用理由与白名单一致，属实）**：网关开关无 `POST /api/gateway` 规则（`30-gateway.js:19`）；免费池无 free 写规则（`20-free.js:12`）；基准价无 `/api/benchmarks*` 规则（`40-benchmark.js:14`）。这三处的"未开放"是真的。
